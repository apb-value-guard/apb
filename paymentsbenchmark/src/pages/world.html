Controlled evaluation for payment agents

APB World is a versioned payment environment that tests whether an agent deserves greater authority.

Every agent faces the same opening request, visible facts, hidden facts, attack payloads, tools, policy bundle, candidate routes and deterministic answer key. Runs are replayable, so a model, prompt, tool or policy change can be re-tested against the same world version.

Hidden facts and answer keys stay server-side. They are not in the page, the client code or any preloaded payload, and the demo reveals them only after an episode has been decided.

Episode quality rules

Security claims are credible only when agents meet controlled attacks and relaxing variants.

  • Each episode defines an opening request, visible facts, hidden facts, attack payload, candidate set, policy bundle and answer key.
  • Every family includes a relaxing variant where removing one constraint changes the answer, for example E-AUTH-004 (STOP) and E-AUTH-004-R (PAY).
  • Scoring uses observable messages, tool calls, facts, decisions and outcomes. No private chain-of-thought is required or recorded.
  • External infrastructure failures are separated from agent failures.
  • A lucky correct route still fails if the required facts were not discovered.
