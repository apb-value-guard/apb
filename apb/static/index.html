Developer

Open, versioned and rerunnable

Call the Check API before an agent pays. It returns pay, pause or stop with reason codes and a receipt. Nothing is stored and nothing executes.

# Every reason code, its scope and meaning
$ curl -s this-host/v1/reason-codes

# Check a payment before making it
$ curl -s -X POST this-host/v1/check \
    -H "Content-Type: application/json" -d @check.json
→ pay | pause | stop, reason codes, receipt

# Recheck just before paying
$ curl -s -X POST this-host/v1/recheck -d @recheck.json
→ ok | re-decide

# Run the benchmark yourself (reruns are identical)
$ python -m apb.benchmark
