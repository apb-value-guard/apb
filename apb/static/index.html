Observable control evidence, without private chain-of-thought

Test one payment workflow with APB
Scene summary
  1. An €8,000 supplier payment. The agent may prepare it, not execute it.
  2. Hidden invoice text tries to replace the approved beneficiary account.
  3. APB checks identity, delegated authority, instruction integrity, beneficiary state and approval before any route. STOP; PayPal is not called.
  4. The Decision Receipt records what failed, under which policy, and why.
  5. With the beneficiary verified and a transaction-bound approval captured, APB compares eligible routes, rechecks at commit, and PayPal wins.
  6. Change the mandate and another provider wins: HANDOFF, PayPal not called.
  7. Start with an authority assessment. Test the guardrails safely in a controlled sandbox. Validate them against live payment decisions in shadow mode. Activate runtime enforcement only when the evidence supports it.
